# ALTRACONEX — démonstration visuelle

Ce dépôt public contient exclusivement l'export statique de la démonstration et sa configuration de publication. Le code source et son historique sont conservés dans un dépôt privé distinct.

Adresse GitHub Pages : https://sleqoh.github.io/altraconex-demo/

Les fichiers de `site/` sont mis à jour automatiquement après validation de la branche principale du dépôt source. GitHub Actions publie ce dossier ; `site/version.json` indique le commit source et les empreintes des fichiers.

Cette présentation utilise des données fictives. Elle ne fournit ni authentification métier, ni paiement, ni service commercial opérationnel. Le lien et les ressources du navigateur sont publics ; `noindex` n'est pas une protection d'accès.
